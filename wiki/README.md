# Парсер фильмов на Scrapy (Wikipedia + доп. IMDb -> CSV)

## Задание

Вам необходимо: используя scrapy, написать парсер, который будет собирать информацию о фильмах:
- Название  
- Жанр  
- Режиссер  
- Страна  
- Год  
- IMDB рейтинг (?)

Парсер должен сохранять результаты в формате CSV.

**Дополнительное задание:** дополнить парсер возможностью собрать рейтинг IMDB к уже собранным фильмам, ресурс можно использовать любой на ваше усмотрение.

**Подсказка:** лучше использовать следующие стартовые страницы:
- Первый вариант — https://ru.wikipedia.org/wiki/Категория:Фильмы_по_алфавиту  


## Описание проекта

Проект реализует Scrapy-паука, который:
1. Проходит по страницам категории фильмов в Википедии (по алфавиту или по годам).
2. Переходит на страницы отдельных фильмов.
3. Извлекает данные из infobox (если доступно): жанр, режиссёр, страна, год, IMDB рейтинг, а также заголовок страницы.
4. Экспортирует результаты в CSV.

## Комментарии автора (Иван Береснев).

1. На сайте википедии слишком удобно лежит ссылка на фильм IMDB, чтобы ей не воспользоваться, поэтому парсим напрямую.
2. Для избежания потери данных из-за ошибки `HTTP 429 Too Many Requests` добавил `Middleware` - `SlotPolicyAndBackoffMiddleware`
3. Для удобства вашего тестирования моего кода был добавлен параметр `max_pages` по-дефолту равный 2 (Вы говорили на лекции, что не будете запускаться и ждать парсинга всего Wiki, а запуститесь на кусочке данных, поэтому счёл добавление такого параметра валидным).
4. В текущей реализации парсинг начинается с первой страницы и продвигается вгрубь. На моих тестах устанавливал `max_pages` в 150 и всё отрабатывало корректно.
5. Была идея купить/найти прокси, да побольше, но всё работает в текущей реализации (возможно, не так быстро, всё-таки ограничиваем скорость загрузки чтобы сразу не забанили, но в задании ограничения на скорость не было)

## Запуск 
По умолчанию парсер берёт первые 2 страницы категории при запуске:
`scrapy crawl wiki_spider -O movies.csv`
Иначе нужно переопределить:
`scrapy crawl wiki_spider -a max_pages=5 -O movies.csv`
